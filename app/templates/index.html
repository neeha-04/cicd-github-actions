CI/CD Pipeline Stages
STAGE 01
🔍 Code Lint
flake8
Runs flake8 on the app/ directory. Checks PEP8 style, unused imports, line length (max 120), and syntax errors. Pipeline fails here if code quality is poor.
✔ passing
STAGE 02
🧪 Automated Tests
pytest + pytest-cov
Runs all 10 tests in tests/ with coverage reporting. Covers all routes, API endpoints, edge cases, and error responses. Coverage report uploaded as artifact.
✔ 10/10 passing
STAGE 03
🐳 Docker Build
Docker + curl smoke test
Builds the Docker image from Dockerfile, starts the container with test env vars, waits 5s, then hits /health with curl. Fails if container doesn't respond.
✔ image built & verified
STAGE 04
📦 Docker Hub Push
docker/build-push-action
Only runs on push to main branch. Logs in to Docker Hub using GitHub Secrets, pushes image tagged as :latest and :commit-sha.
✔ pushed to registry

CICD//PIPELINE

Production-ready CI/CD automation · GitHub Actions · Docker · Flask · Pytest

🐍 PYTHON 3.11 ⚡ FLASK 🐳 DOCKER 🧪 PYTEST ⚙️ GITHUB ACTIONS
🎯 Project Purpose
This project demonstrates a complete CI/CD pipeline using GitHub Actions for a Dockerized Flask application. Every push to the main branch automatically triggers lint checks, test runs, Docker image builds, and registry pushes — with zero manual intervention.
🏗️ Pipeline Architecture
📥 Code Push → GitHub
  └── Trigger GitHub Actions Workflow
      ├── Stage 1: Flake8 Lint
      ├── Stage 2: Pytest (10 tests)
      ├── Stage 3: Docker Build + Smoke Test
      └── Stage 4: Push to Docker Hub
